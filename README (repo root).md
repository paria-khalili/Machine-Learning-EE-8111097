# Machine Learning — EE 8111097

Coursework and final project for the Machine Learning course at the University of Tehran (Fall 2025). Each folder below is a self-contained assignment with its own report/notebook and, where relevant, its own README.

## Contents

| Folder | Topic |
|---|---|
| [Homework 1](./Homework%201) | Statistical learning foundations: Bayes decision theory, Gaussian decision boundaries, MLE for Bernoulli/Poisson models, least squares as MLE, Naive Bayes spam filtering, and a custom pixel-based image classifier |
| [Homework 2](./Homework%202) | Genetic Algorithm–based jigsaw puzzle solver (fit score, puzzle fitness, selection, evolution loop) built on the GAPS library |
| [Homework 3](./Homework%203) | SVM classification: diabetes diagnosis (preprocessing, scaling, linear/kernel SVM) and social network ad purchase prediction |
| [Homework 4](./Homework%204) | Dimensionality reduction (PCA/Kernel PCA on Iris), feature selection on a heart-disease dataset, and K-Means/GMM image segmentation |
| [Homework 5](./Homework%205) | Polynomial regression and a PyTorch neural network trained on image data |
| [Final Project Phase 1](./Final%20Project%20Phase%201) | Project proposal/report for a Spoken Language Identification (SLID) system |
| [Final Project Phase 2](./Final%20Project%20Phase%202) | Full SLID pipeline: audio cleaning, feature extraction (MFCCs + spectral features), classification, clustering, and evaluation |

## Structure

Each homework folder generally contains:
- The assignment PDF (prompt/instructions)
- A written report and/or Jupyter notebook with the solution
- Supporting datasets/images used in that assignment

See each folder's README for details specific to that assignment.
