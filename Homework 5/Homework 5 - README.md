# Homework 5: Polynomial Regression & Neural Networks

Two exercises spanning classical regression and deep learning.

## What it covers

- **Q4 — Polynomial regression** (`Q4.ipynb`): Builds polynomial feature expansions (`[1, x, x², ..., x^d]`) from scratch and fits regression models of varying degree to study underfitting/overfitting behavior as model complexity increases.
- **Q10 — Neural network with PyTorch** (`HW5_Q10.ipynb`): Defines, trains, and evaluates a neural network using `torch`/`torchvision` on an image dataset, including device setup (CPU/GPU) and the training loop.

## Contents

- `Q4.ipynb`, `HW5_Q10.ipynb` — notebooks for each question
- `Homework_5 (1).pdf`, `تمرین__5_.pdf` — assignment prompt (English and Persian)
