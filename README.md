# Machine Learning — EE 8111097

Coursework and final project for the Machine Learning course at the University of Tehran (Fall 2025). Each folder below is a self-contained assignment with its own report/notebook and, where relevant, its own README.

## Contents

| Folder | Topic |
|---|---|
| [Genetic Algorithms for Image Reconstruction](./Genetic%20Algorithms%20for%20Image%20Reconstruction) | Genetic Algorithm–based jigsaw puzzle solver (fit score, puzzle fitness, selection, evolution loop) built on the GAPS library |
| [Support Vector Machines for Medical and Behavioral Classification](./Support%20Vector%20Machines%20for%20Medical%20and%20Behavioral%20Classification) | SVM classification: diabetes diagnosis (preprocessing, scaling, linear/kernel SVM) and social network ad purchase prediction |
| [Dimensionality Reduction, Feature Selection, and Image Segmentation](./Dimensionality%20Reduction%2C%20Feature%20Selection%2C%20and%20Image%20Segmentation) | Dimensionality reduction (PCA/Kernel PCA on Iris), feature selection on a heart-disease dataset, and K-Means/GMM image segmentation |
| [Polynomial Regression and Neural Networks](./Polynomial%20Regression%20and%20Neural%20Networks) | Polynomial regression and a PyTorch neural network trained on image data |
| [Final Project, Phase 1 - Problem Formulation](./Final%20Project%2C%20Phase%201%20-%20Problem%20Formulation) | Project proposal/report for a Spoken Language Identification (SLID) system |
| [Final Project, Phase 2 - Modeling Pipeline](./Final%20Project%2C%20Phase%202%20-%20Modeling%20Pipeline) | Full SLID pipeline: audio cleaning, feature extraction (MFCCs + spectral features), classification, clustering, and evaluation |

## Structure

Each folder generally contains:
- The assignment PDF (prompt/instructions)
- A written report and/or Jupyter notebook with the solution
- Supporting datasets/images used in that assignment

See each folder's README for details specific to that assignment.
